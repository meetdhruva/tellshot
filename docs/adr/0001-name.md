# 0001. Name the product Tellshot

**Status:** accepted · **Date:** 2026-11-02

## Context

The name must be easy to find: a search for it should return this project, not a crowd of
unrelated results. It should also hint at the job (showing someone what you see).

## Decision

**Tellshot** ("show and tell" + "screenshot"). On 2026-11-02 it had no exact-match web results,
one unrelated GitHub repository, and no crates.io crate.

Rejected after the same checks: Klarshot (sounds like CleanShot and ClearShot, both screenshot
tools), Pixtell (PixTeller, Pixetell), Glimmark (close to Glenmark), Pixfold (Pixel Fold).

## Consequences

- Crates are `tellshot-*`, binaries `tellshot` and `tellshot-editor`, project files `.tellshot`.
- Before a public launch, check trademarks in target markets and register domains and the GitHub
  organisation.
